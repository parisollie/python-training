# Python Training

Capacitación completa de Python (Fundamental → Intermediate → Advanced) con proyecto integrador usando la API de Rick and Morty y arquitectura hexagonal.

## Stack

- Python 3.12.15
- Poetry 2.5.1
- Git 2.54.0
- VS Code
- FastAPI, httpx, pytest, ruff, black, isort, mypy

## Estructura

- `00_setup/` - Instalación y configuración
- `01_fundamental/` - Nivel Fundamental (módulos 01-07)
- `02_intermediate/` - Nivel Intermediate (módulos 08-15)
- `03_advanced/` - Nivel Advanced (módulos 16-20)
- `04_laboratorios/` - Laboratorios prácticos
- `05_proyecto_final/` - Proyecto integrador
